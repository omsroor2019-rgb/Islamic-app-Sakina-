# سَكينة | Sakinah

تطبيق إسلامي عربي لأندرويد بواجهة خضراء وبيضاء، مبني باستخدام Flutter وDart.

## الوظائف المضمنة في الإصدار 1.1

### القرآن الكريم
- فهرس 114 سورة، وقراءة النص العثماني من AlQuran Cloud.
- تنزيل نص المصحف كاملاً إلى مساحة التطبيق الخاصة للاستخدام دون اتصال.
- البحث داخل الآيات مع تطبيع التشكيل واختلافات الألف والهمزة والياء.
- حفظ الآيات في قائمة علامات محلية.
- إنشاء بطاقة PNG أنيقة للآية ومشاركتها من نافذة المشاركة في أندرويد.
- خطة ختمة قابلة للتخصيص بمدد 7 أو 15 أو 30 أو 40 أو 60 أو 90 يوماً، مع تحديث موضع القراءة ومؤشر التقدم.

### العبادات والأذكار
- أذكار وأدعية وأحاديث مختارة مع إحالات المصادر المتاحة داخل التطبيق.
- سبحة إلكترونية تحفظ العدد محلياً.
- متتبّع يومي للصلوات الخمس والأعمال النافعة، مع احتساب سلسلة أيام المحافظة على الصلوات الخمس وفق التسجيل اليدوي.
- التلاوات الصوتية بخمسة خيارات للقارئ، وتشغيل السورة أو طلب تنزيل المصحف الصوتي كاملاً للاستخدام الشخصي داخل التطبيق.

### الصلاة والخدمات
- مواقيت صلاة محسوبة محلياً مع عرض الصلاة القادمة والوقت المتبقي، وتحديث الشاشة كل دقيقة.
- موقع افتراضي للمكلا، مع خيار تحديد الموقع بعد منح الإذن.
- بوصلة قبلة تعتمد على الموقع ومستشعر المغناطيسية.
- تسجيل أذان CC0 قابل للتشغيل والتنزيل بطلب المستخدم.
- تاريخ هجري تقريبي، وصفحة دعم اختياري، وإعدادات ومصادر وحقوق واضحة.

### الخصوصية
- لا يتطلب إنشاء حساب أو تسجيل دخول.
- لا يتضمن المشروع أدوات تحليلات أو إعلانات أو ملفات تتبع.
- حفظ التقدم والعلامات والإعدادات والملفات المنزّلة في مساحة التطبيق المحلية.
- الاتصال بالإنترنت مطلوب لجلب نص القرآن عند عدم وجود نسخة مخزنة، وللتنزيلات الصوتية. لا يرسل التطبيق ملف عبادات المستخدم أو قائمة العلامات إلى خادم.
- إذن الموقع اختياري، ويستخدم لحساب المواقيت واتجاه القبلة فقط.

### ما يحتاج التحقق قبل النشر العام
- هذا الإصدار يستخدم الواجهة الفاتحة الخضراء والبيضاء؛ الوضع الداكن، والتفسير المدمج، والترجمات، وعرض المصحف بصفحات مطابقة للمصحف الورقي ليست ضمن الوظائف الحالية.
- لا توجد في هذه النسخة جدولة موثوقة للأذان أو الإشعارات في الخلفية؛ الأذان المتاح تسجيل قابل للتشغيل وليس منبهاً تلقائياً.
- التلاوات حقوقها لأصحابها، وAlQuran Cloud يسمح بالبث والتنزيل الشخصي/التعليمي مع بقاء حقوق التسجيلات لأصحابها؛ يجب مراجعة الشروط وأي موافقات لازمة قبل الاستخدام التجاري.
- يجب اختبار البوصلة ومواقيت الصلاة على أجهزة أندرويد فعلية ومقارنتها بالتقويم المعتمد محلياً.
- التاريخ الهجري تقديري وقد يختلف يوماً بسبب رؤية الهلال.

## بناء APK عبر GitHub من الهاتف

يستخدم مسار البناء Flutter stable وJDK 17، ويشترط Flutter 3.29 أو أحدث.

1. أنشئ مستودعاً جديداً على GitHub وارفع **كل محتويات** مجلد المشروع، بما فيها المجلد المخفي `.github`.
2. افتح المستودع ثم تبويب **Actions**.
3. اختر **Build Sakinah Android APK** ثم اضغط **Run workflow**.
4. انتظر حتى تنتهي جميع خطوات التحليل والاختبارات والبناء بعلامة نجاح خضراء.
5. افتح تشغيل البناء ثم نزّل الملف المضغوط من قسم **Artifacts** باسم `SAKINAH-ANDROID-APK`، وبعد فك ضغطه ستحصل على `app-release.apk`.

> لا يوجد APK مرفق داخل حزمة المصدر هذه. لا تعتبر البناء ناجحاً إلا بعد نجاح GitHub Actions وظهور ملف APK في Artifacts.

الـ Workflow ينشئ مشروع Android المضيف باستخدام `flutter create` ثم يجلب الحزم ويحلل الكود ويشغل الاختبارات ويبني APK. نجاح إعداد الملفات أو الاختبارات المحلية لا يعني أن APK قد بُني؛ تأكد من نجاح تشغيل GitHub Actions قبل تثبيت الناتج.

## المحتوى والاتصال

- فهرس السور مضمّن داخل التطبيق.
- نص القرآن يأتي من AlQuran Cloud. أول قراءة لسورة تحتاج اتصالاً، ويمكن تنزيل نص المصحف كاملاً من صفحة القرآن لحفظه محلياً.
- التلاوات الصوتية لا تُضمّن في APK. يطلب المستخدم تنزيلها اختيارياً إلى مساحة التطبيق الخاصة للاستماع دون إنترنت. التوفر يعتمد على معرفات الإصدارات الصوتية لدى مزود الخدمة.
- الأذان الصوتي المستخدم من Wikimedia Commons: `Beautiful adhan.ogg` للمؤلف Adam-synagda، CC0 1.0. التطبيق يبثه من المصدر أو ينزله المستخدم إلى مجلد التطبيق الخاص.
- مواقيت الصلاة محسوبة محلياً؛ الإعداد الافتراضي للمكلا مؤقت ويجب تثبيت الموقع الصحيح قبل الاعتماد على المواقيت.
- القبلة تحتاج مستشعر مغناطيسية. قد تتأثر القراءة بالمعادن أو ضعف المستشعر.
- لا يتضمن الإصدار الحالي جدولة أذان كامل تلقائي في الخلفية. صفحة الأذان تسمح بتشغيل التسجيل الكامل أو تنزيله. مواقيت الصلاة معروضة داخل التطبيق.
